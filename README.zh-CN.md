## 覆盖的实验

同一套脚本用于三个 VR 刺激的脑电实验：

| 序号 | 实验 | 切分出的类别 |
|---|---|---|
| 1 | 手写汉字的不同笔画脑电信号分类 | 横 / 竖 / 撇 / 捺 / 点 / 其他 |
| 2 | 情绪神经信号分析（恐怖类 VR 视频） | `V_49`、`V_92`、`V_212`、`V_208`（按视频长度命名） |
| 3 | 不同种类物品的视觉刺激分类 | `V1` … `V6` |

三个实验在采集脑电信号的同时，均采集了心电信号。

## 处理流程（`epoching.py`）

每次录制使用两份数据文件：

- **保留** `HL 2` 标记通道的版本 —— 用来定位标记点（切段点）
- **删掉** `HL 2` 的版本（EEGLAB 手动另存）—— 用来真正切分数据

### 标记点检测（改进版双模式）

| 参数 | 取值 | 作用 |
|---|---|---|
| `baseline` | `-5550e-6` V | 静息基线 |
| `relative_thresh` | `2200e-6` V | 相对基线的偏差阈值 |
| `gap_fill_sec` | `0.06` s | 用 `binary_closing` 填补块内小于 60 ms 的间隙 |
| `short_block_sec` / `long_block_sec` | `0.6` s / `0.8` s | 信号块长短的判定阈值 |
| `short_min_gap_sec` / `long_min_gap_sec` | `0.3` s / `2.0` s | 相邻标记点之间的死区 |

步骤：

1. 用 `mne.io.read_raw_eeglab` 读取 `HL 2` 通道，展平成一维，取出 `sfreq`
2. 以 `abs(data - baseline) > relative_thresh` 做阈值判定
3. `binary_closing` 填补同一个标记内部的小间隙，避免一个标记被判成多块
4. 用 `scipy.ndimage.label` 找出连续块，丢弃长度小于 5 个采样点的噪声块
5. 按块长短套用不同的死区，保证一个物理标记只产生一个触发点
6. 用 matplotlib 绘制信号、基线与被检测到的触发点，便于人工核对

### 切段保存

- `split_and_save(start, end, n_segments, category)`：把某个时间戳区间均分成若干份，逐份写入以类别命名的文件夹
- 相邻标记之间的区间直接舍弃
- `split_and_save_with_skip(..., skip_sec=3.0)`：在均分的基础上，每份再舍去最前面的 N 秒

## 学习与实验笔记

### 1. 脑电基础

#### 1.1 电极点位

**10-20 系统**

| 位置 | 说明 |
|---|---|
| 鼻梁根部往上 | 10% |
| FP 前额叶 | 20% |
| F 额叶 | 20% |
| C 中心区 | 20% |
| P 顶叶 | 20% |
| O 枕叶往下 | 10% |
| Z | 中轴线 |

- 中轴线左边为奇数点位，右边为对称的偶数点位（如 C1、C2 关于中轴线对称，一左一右）。

**10-10 系统**

- 把 10-20 系统中占 20% 的脑区再从中划分成 10% 和 10%，点位更密。

#### 1.2 脑区分叶与功能

| 脑区 | 代号 | 功能 |
|---|---|---|
| 前额叶 | FP | 高级思考 |
| 额叶 | F | — |
| 中心区 | C | 运动 |
| 顶叶 | P | — |
| 枕叶 | O | 视觉 |
| 颞叶 | — | 位于顶叶、额叶下方，负责视觉记忆、语言、情感、长期记忆（海马体） |

#### 1.3 脑电波划分

**医学经验划分的 5 种脑电波**

| 波段 | 频率 | 幅值 | 相关状态 |
|---|---|---|---|
| delta | 0.1–4 Hz | 20–200 μV | 深度睡眠、记忆生成 |
| theta | 4–8 Hz | 10–50 μV | 运动想象、记忆编码（困难任务信号强）、疲劳 |
| alpha | 8–12(13) Hz | 20–100 μV | 平静；枕叶、顶叶容易检测；大脑最明显的波频 |
| beta | 12(13)–30 Hz | 5–20 μV | 运动、镜像运动 |
| gamma | > 30 Hz | 振幅小 | 与注意力高度集中相关 |

**均分频段法（工程思维）**

- 每 2 Hz 切分一个频段，共 25 段（对应中国 50 Hz 工频信号）。

#### 1.4 脑电的本质与采集层次

- 脑电本质是生物电；但受当前技术限制，实际采集到的基本是**突触后膜电位**。

| 类型 | 采集方式 |
|---|---|
| 脑电图 EEG | 通过头皮测量 |
| 皮层脑电图 ECoG | 不伤害脑膜，在脑膜上测量 |
| 局部场电位 | 电极深入到某个脑区进行测量 |

#### 1.5 伪迹

- 采集到的信号除了脑电信号之外还包含伪迹（噪声）。
- 需要做去伪迹操作。

#### 1.6 硬件设备

**脑电帽**

- 作用电极（active electrode）
- 参考电极（reference electrode）
- 接地电极（ground electrode）

**放大器**

| 指标 | 要求 | 说明 |
|---|---|---|
| 输入阻抗 | > 10 GΩ | — |
| 共模抑制比 CMRR | > 100 dB | 对差模信号放大、对共模信号抑制 |
| 频率响应 | — | 不需要 1000 Hz 以上的信息 |

**数模转换器（ADC）**

- 作用：把模拟信号转换为数字信号。
- 分辨率：以 bit 表示（2 的 bit 次方分辨），一般大于 20。

### 2. 实验流程

#### 2.1 目标与范式

- 主试应通过实践摸索范式，或直接套用成熟的范式。
- 先设定实验目标，再确定实验方案与范式。

#### 2.2 四类采集范式

**1）稳态视觉诱发 SSVEP**

- 通过枕叶采集，分辨率大于 95%，通过 PPT 光刺激实现。
- 优点：识别准确度高。
- 缺点：只能二分类；不能长期佩戴；有光敏性癫痫风险。

**2）运动范式**

- 运动想象（MI）
- 运动执行（ME）
- 发展方向：脑控取物。

**3）情感范式**

**4）疾病诊断**

#### 2.3 采集建议

- **脑电电极**：湿电极 Ag/AgCl 更好；脑电膏优于生理盐水。
- **脑电帽佩戴位置**：前端在鼻梁根部，后端在枕骨隆突。
- **被试满意度是高质量数据的重要保证**：
  1. 与被试交谈，让其放松
  2. 确保实验的合理时间长度
  3. 提供小吃、零食、饮料，播放背景音乐放松
  4. 提供奖励，做好实验后加钱
- **眨眼**：让被试控制眨眼周期，在休息时眨眼。
- **视频显示器**：距离 1–2 m。
- **采集电极不要过多**，避免造成干扰。

#### 2.4 硬件分类

| 类型 | 特点 |
|---|---|
| 侵入式 | 数据质量好；成本高、对被试有伤害 |
| 非侵入式 | 便携、安全、主试自由度高；缺点是漂移 |
| 介入式 | — |

**侵入式**

- **全侵入式**：手术植入，采集 spike 尖峰放电，电极插入脑区（清华大学洪波教授）。
- **半侵入式**：不破坏脑膜，电极放在脑膜上（浙江大学）。
  - 优点：数据质量好
  - 缺点：成本高，对被试有伤害
  - 技术：微电极阵列、深脑刺激式
  - 防止了头发、头皮、颅骨、脑膜、空腔对脑电信号测量的干扰

**非侵入式**

- 优点：便携、安全、主试自由度高。
- 缺点：漂移 —— 信号漂移（试验期间脑电信号漂移）与电极漂移（实验期间脑电帽物理移动）。
- 通道数量可选 2、3、16、64、256，越多数据质量越好。

### 3. 数据预处理

- 脑电信号 = 大脑活动信号 − 参考电极记录的生物电信号。

#### 3.1 建议

| 项目 | 建议 |
|---|---|
| 采样率 | 250 Hz 或 1 kHz 足够 |
| 环境与噪声 | 特殊屏蔽室、主动电极系统、凹陷滤波器 |
| 数模转换器 | 20 bit 以上；尽量无需做高通；分辨率达不到要求时，用 0.01 Hz 或 0.1 Hz 高通 |
| 在线采集 | 参数宽泛一些，少一点滤波 |

#### 3.2 标准步骤

1. 导入 EEG 数据到电脑中（格式：CSV、mat、daq、fif）
2. 以本次试验的原始电极位置绘制三维脑图（由外部数据库提供位置信息）
3. 滤波（工频信号滤波、低通滤波、高通滤波、带通滤波、巴特沃斯滤波器）
4. 去伪迹（眼电信号、肌电信号）
5. *(选做)* 重参考 —— 参考电极一般都能正常工作；参考电极坏了时用 CZ 位置电极作重参考（参考电极放在耳垂上）
6. **切段** —— 根据采集范式的时间戳，将整段信号数据切分出样本
7. 剔除坏段、插值坏导 —— 剔除有干扰的坏段，插入其他样本数据
8. *(选做)* 结果数据可视化
9. 保存数据

#### 3.3 EEGLAB 实操（MATLAB）

启动：在 MATLAB 中设置路径 → 载入 EEGLAB 文件地址 → 命令框输入 `eeglab` 打开。

**1. 导入数据，查看数据基本内容**

- 使用 `extensions - loadcurry` 插件
- `import data` → `using EEG function and plugins` → `from Neuroscan file`

**2. 输入事件与电极位置**

- 事件：`.ceo` 文件通常作为事件文件，可通过 `file - import event info - from ASCII file` 载入
- 电极位置：`.dpo` 文件是电极位置文件，但 loadcurry 插件在 Import data 这一步已经加载了附带的电极位置文件
  - 从 `edit - channel locations - plot 2D/3D` 查看电极位置
  - 发现 F11、F12、FT11、FT12 通道没有位置信息
  - 在 `edit - channel locations` 中尝试 `look up locs`（使用了 Neuroscan 标题的几个文件），不仅没补上通道位置信息，反而把原有位置信息也丢了

**3. 重参考与数据降采样**

- 重参考：`tool - re reference` → 选择 channel 作为重参考通道。Curry 9 参考电极良好，不需要重参考
- 数据降采样：`tool - change sampling rate` → 250 Hz

**4. 滤波**

- `tool - filter the data` → 带通滤波，可以选择不需要滤波的通道
- 经查资料设置为 0.1–40 Hz（正式实验通常 8–30 Hz）

**5. 数据可视化**

- `plot - channel data (scroll)` 查看所有通道数据，同时检查坏道与坏段

**6. 去除坏道**

- **直接删除**：手动 `edit - select data - channel range` 输入不要的通道，勾选 remove（坏道完全无数据、数量少）
- **插值坏导**：`tools - interpolate electrodes - select from data channel`（坏道部分数据有效、有恢复价值，或坏道数量多）

**7. 去除坏段**

- 在数据可视化界面选中片段 → `reject` 去除
  - 用 norm、stack 归一化比较直观，可以看长时间数据有没有伪迹（识别大肌肉伪迹、眼动伪迹）
  - 如何区分坏段？记录被试在实验中做其他事情造成的干扰
- 调用 `tool - decompose data by ICA` 做 ICA
- `classify components by ICLabel` 自动判断眼动伪迹并去除

**8. 将实验数据分段**

- 用**保留 HL 2** 的版本定位切段点，用**删掉 HL 2** 的版本切成若干份放入文件夹
- 具体做法见下方「5. 具体切段方案」

### 4. 数据分析处理

- 有效数据样本量少时，将**临近脑区的数据用加权平均算法**处理后，再交给机器学习和深度学习。
- 机器学习和深度学习提高分辨率的步骤是**特征提取**，方法包括：
  - 时域分析
  - 频域分析
  - 空域分析
  - 时频域分析

最终目标：得出结论、进行预测。

### 5. 具体切段方案：书写汉字实验

- 时间戳序号用数字标记（对应 `epoching.py` 中的 `t[0]`、`t[1]` …）。
- **相邻两个标记之间**为一段内容，**每两段内容之间舍弃一段**。

| 时间戳区间 | 处理方式 | 保存到 |
|---|---|---|
| 1–2 | 舍弃 | — |
| 2–3 | 均分 25 份 | `横` |
| 3–4 | 舍弃 | — |
| 4–5 | 均分 25 份 | `竖` |
| 5–6 | 舍弃 | — |
| 6–7 | 均分 25 份 | `撇` |
| 7–8 | 舍弃 | — |
| 8–9 | 均分 25 份 | `捺` |
| 9–10 | 舍弃 | — |
| 10–11 | 均分 25 份 | `点` |
| 11–12 | 舍弃 | — |
| 12–13 | 均分 40 份（按 横、竖、撇、捺 顺序循环 10 次） | 对应笔画文件夹 |
| 13–14 | 舍弃 | — |
| 14–15 | 均分 90 份（按 撇、横、竖、撇、点、点、点、横、竖 顺序循环 10 次） | 对应笔画文件夹 |
| 15–16 | 舍弃 | — |
| 16–17 | 均分 10 份 | — |

其余区间（23–24、26–27、28–29、30–31 等）在 `epoching.py` 中已写好完整的类别序列与调用示例，可直接参照修改。
